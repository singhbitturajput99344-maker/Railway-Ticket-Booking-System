# 🚆 Railway Ticket Booking System

## About Project
The Railway Ticket Booking System is a Java-based application with a Graphical User Interface (GUI). It helps users manage railway ticket booking information.

## Features
- Passenger Details
- Passenger Name
- Gender Selection
- Ticket Booking Information
- User-Friendly Interface

## Technologies Used
- Java
- Java Swing
- VS Code
- Git
- GitHub
